# Quant Portfolio Manager — A Career Guide (GitHub Pages site)

Static single-page guide on **quantitative portfolio management as a career**, part of the PrakharQuant finance career series.

## Contents
- **The Role** — what a quant PM actually owns: alpha, risk budget, P&L, team, capacity, infrastructure
- **Terminology Decoder** — 45 filterable terms across Alpha & Signals, Performance, Portfolio Construction, Costs & Implementation, Risk & Drawdown, Business & Fees (IC/IR, breadth, Fundamental Law, deflated Sharpe, MVO, Barra risk models, crowding, slippage, TCA, hard/soft dollars…)
- **Key Skills** — weighted skill bars + interview reality check
- **Strategy Universe** — equity MN, L/S, CTAs, macro, stat arb, RV, vol, HFT, crypto, multi-strat pods
- **Research Pipeline** — data → idea → backtest → construction → deployment → kill/compound
- **Who Hires** — hedge funds, systematic asset managers, prop shops, banks, SWFs, fintech; geography
- **Career Path** — researcher → senior researcher → sub-PM → PM → CIO/founder timeline
- **Compensation** — structures and indicative ranges by stage
- **Breaking In** — education routes, portfolio proof, competitions, reading list

Created by [Prakhar Gupta](https://www.linkedin.com/in/prakhar-gupta-5b7250372/) · [X @PrakharQuant](https://x.com/PrakharQuant) · bestofprakhar@gmail.com

## Deploying on GitHub Pages
1. Settings → Pages → Source: **Deploy from a branch**
2. Branch: `main`, folder: `/(root)` → Save
3. Live at `https://prakharquant.github.io/quant-portfolio-manager/` within 1–2 minutes.

The site is a single self-contained `index.html` — no build step, no dependencies.
